## Da sapere

- I file di prova di una review messi in `to-be-deleted-after-use/` senza un `go.mod` loro entrano in
  `go vet ./...` e fanno cadere `scripts/check`: ogni cartella con file `.go` lì dentro vuole un
  `go.mod` (o va tolta prima del check).
- `banco giu` cancella la cartella dell'istanza con `esito/esito.json`: per i numeri della copertura
  con il banco si copia l'esito (o si lancia `tools/copertura -banco`) prima di `giu`.
