# GestRip

Gestione delle riparazioni per oreficerie e orologerie: un apparecchio che sta in
negozio, con l'intelligenza artificiale in locale. I dati dei clienti non escono
dal negozio.

Stato: **progettazione**. Il piano di lavoro è in [`docs/PIANO.md`](docs/PIANO.md).

Questo repository è pensato come pubblico fin dal primo commit: contiene solo
codice e dati inventati. Niente segreti, niente dati veri di clienti, buste,
foto, dettati, persone o negozi.
